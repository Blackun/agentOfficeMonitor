🏢 AGENT OFFICE MONITOR

Antigravity & Claude Code 멀티 에이전트 실시간 2D 픽셀 오피스 관제 대시보드

01 · Problem (페인포인트)

어떤 문제를 해결하고자 했나요?

Antigravity와 Claude Code 등 여러 AI 에이전트를 동시에 띄워놓고 일할 때, 각 에이전트가 현재 코딩 중인지, 사용자 승인을 기다리며 멈춰 있는지 확인하기 위해 수많은 터미널과 탭을 일일이 오가야 하는 번거로움을 해결하고자 했습니다.

02 · Solution (서비스 구현)

그래서 어떤 서비스를 만들었나요?

로컬 에이전트들의 작업 로그(JSONL)와 Hook 이벤트를 실시간 감지해, 좌측 Antigravity 사무실 · 우측 Claude Code 사무실 · 중앙 공용 휴게실로 구성된 2D 픽셀 오피스에서 캐릭터 애니메이션과 말풍선으로 시각화하는 웹 모니터를 만들었습니다.

03 · Impact (업무 효과)

내 업무에 어떤 도움을 주나요?

내 응답을 기다리는 에이전트(WAITING)와 휴게실에서 쉬고 있는 유휴 에이전트(BREAK)를 한눈에 발견해 즉시 다음 작업을 지시할 수 있으며, 창 전환 피로도를 줄이고 세션별 토큰 소모량을 실시간으로 관리할 수 있습니다.

🖥️ 실제 서비스 실행 화면 (Live Dashboard)

Antigravity 5명 · Claude Code 4명 총 9명의 에이전트가 각 사무실과 중앙 공용 휴게실에서 실시간 동작 중인 화면

🟡 좌측: ANTIGRAVITY OFFICE

~/.gemini/antigravity/brain 세션을 실시간 감지하여 전용 데스크(AGY-1~6)에서 코딩·터미널·추론 상태를 표시합니다.

☕ 중앙: SHARED LOUNGE (공용 휴게실)

양쪽 사무실 에이전트가 작업 대기(BREAK) 상태가 되면 중앙 통로를 통해 공용 휴게실로 모여서 커피를 마시며 휴식합니다.

🟠 우측: CLAUDE CODE OFFICE

~/.claude/projects 로그 및 Hook 이벤트를 감지하여 전용 데스크(CLD-1~6)에서 Claude 에이전트 작업을 시각화합니다.

📊 우측 패널: 실시간 인스펙터 & 로그

출근 에이전트 칩 선택 시 최근 프롬프트, 현재 추론(Thinking), 누적 스텝/토큰과 실시간 타임라인 피드를 제공합니다.

🏗️ 전체 시스템 & Podman 컨테이너 아키텍처
